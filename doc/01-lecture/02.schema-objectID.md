```js
likedSongs: [
  {
    type: mongoose.Schema.Types.ObjectId,
    ref: "Song",
  },
],
```

### რა ნიშნავს ეს?

- `likedSongs` არის **array field** `User` სქემაში.
- თითო ელემენტი არის **ObjectId**, რომელიც უკავშირდება `"Song"` მოდელს (ანუ `songs` კოლექციაში არსებულ დოკუმენტს).
- `ref: "Song"` მხოლოდ იმას ნიშნავს, რომ ეს ID **სწორედ Song მოდელს მიეკუთვნება**, და მოგვიანებით შეგიძლია გამოიყენო `populate`.

---

### მაგალითი

#### მოდელები:

```js
const userSchema = new mongoose.Schema({
  name: String,
  likedSongs: [
    {
      type: mongoose.Schema.Types.ObjectId,
      ref: "Song",
    },
  ],
});

const User = mongoose.model("User", userSchema);

const songSchema = new mongoose.Schema({
  title: String,
  artist: String,
});

const Song = mongoose.model("Song", songSchema);
```

#### ახალი სიმღერების შექმნა:

```js
const song1 = await Song.create({ title: "Numb", artist: "Linkin Park" });
const song2 = await Song.create({
  title: "Believer",
  artist: "Imagine Dragons",
});
```

#### იუზერის შექმნა ლაიქებული სიმღერებით:

```js
const user = await User.create({
  name: "Mindia",
  likedSongs: [song1._id, song2._id],
});
```

MongoDB-ში `user` ასე დამჯდარა:

```json
{
  "_id": "...",
  "name": "Mindia",
  "likedSongs": [
    ObjectId("id_of_song1"),
    ObjectId("id_of_song2")
  ]
}
```

---

### `populate` მაგია

თუ გვინდა მხოლოდ ID-ები კი არა, მთლიანად სიმღერის ინფო წამოვიღოთ:

```js
const populatedUser = await User.findById(user._id).populate("likedSongs");

console.log(populatedUser.likedSongs);
```

ეს დააბრუნებს:

```json
[
  { "_id": "id_of_song1", "title": "Numb", "artist": "Linkin Park" },
  { "_id": "id_of_song2", "title": "Believer", "artist": "Imagine Dragons" }
]
```

---

**`likedSongs` იქნება array, სადაც შეინახება დალაიქებული სიმღერების `_id`-ები `Song` მოდელიდან.**
