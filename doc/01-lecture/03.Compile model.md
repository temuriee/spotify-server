```js
const User = mongoose.model("User", userSchema);
module.exports = User;
```

---

🔹 **პირველი ხაზი**
`mongoose.model("User", userSchema)`

- წარმოიდგინე, შენ გაქვს **სახლის ნახაზი** (ეს არის `userSchema`).
- `mongoose.model` ამ ნახაზის მიხედვით **აშენებს რეალურ სახლს** → ანუ ქმნის **მოდელს**.
- `"User"` არის სახელი, რომლითაც შენ ამ სახლს იცნობ (მოდელის სახელი).
- MongoDB-ში ის ავტომატურად შექმნის **users** კოლექციას (ყოველთვის პატარა და მრავლობითში).

ახლა `User` ცვლადი არის „მშენებლობის ინსტრუმენტი“, რომლითაც შეგიძლია:

- ახალი იუზერი შექმნა,
- იუზერები მოძებნო,
- იუზერები შეცვალო,
- იუზერები წაშალო.

---

🔹 **მეორე ხაზი**
`module.exports = User;`

- უბრალოდ **გარე სამყაროს აძლევს ამ ინსტრუმენტს**.
- ანუ თუ სხვა ფაილში გინდა იმუშაო იუზერებზე, შეგიძლია დაწერო:

```js
const User = require("./models/User");
```

და უკვე ეს „ინსტრუმენტი“ იქაც ხელმისაწვდომი იქნება.

---

✅ მოკლედ:

- **Schema** (`userSchema`) → ეს არის **ნახატი** (როგორი უნდა იყოს სახლი).
- **Model** (`User`) → ეს არის **ინსტრუმენტი/ფაბრიკა**, რომელიც ამ ნახატის მიხედვით ახალ სახლებს აშენებს.
- **Document** (`new User(...)`) → ეს არის უკვე **აშენებული სახლი**, კონკრეტული იუზერის მონაცემებით (მაგალითად Mindia, 26 წლის, email-ით).

---

### ანუ:

- `User` (Model) **ინსტრუმენტია**, რომელიც ახალი დოკუმენტების (`user`) შექმნაში გეხმარება და MongoDB-ში მუშაობს.
- თვითონ იუზერები, რომლებსაც შექმნი `new User(...)` ან `User.create(...)` → ესენი უკვე **ნაგებობები/ობიექტები** არიან შენს ბაზაში.

---

MongoDB-ში ასეა სტრუქტურა:

- **Document** → ერთი კონკრეტული ჩანაწერი (მაგ. ერთი იუზერი: `{ name: "Mindia", age: 25 }`)
- **Collection** → დოკუმენტების „მშობელი ყუთი“, სადაც ბევრი მსგავსი დოკუმენტი ინახება (მაგ. **users**)
- **Database** → კოლექციების „მშობელი“, სადაც ბევრი კოლექციაა (მაგ. **myAppDB**)
- **MongoDB Server / Cluster** → ყველა ბაზის „დიდი მშობელი“ 😅

### მაგალითი


👉 ეს არის **document**

ეს დევს `users` კოლექციაში
👉 `users` არის **collection**

`users` კოლექცია არის `myAppDB` ბაზაში
👉 `myAppDB` არის **database**

და ბოლოს ეს ყველაფერი MongoDB სერვერზეა.
