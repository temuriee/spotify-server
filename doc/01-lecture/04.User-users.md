### 🔹 როგორ გადადის `"User"` → `"users"`

როდესაც წერ:

```js
const User = mongoose.model("User", userSchema);
```

- `"User"` არის **მოდელის სახელი** (Model name).
- Mongoose ავტომატურად **გადაიყვანს** ამ სახელს კოლექციის სახელად MongoDB-ში, ასეთ წესებით:

1. **პატარა ასოებში გადაიყვანს**
   `"User"` → `"user"`

2. **მრავლობითში გადააქცევს**
   `"user"` → `"users"`

3. **განსაკუთრებული შემთხვევები აქვს**

   - `"Person"` → `"people"`
   - `"Mouse"` → `"mice"`
   - `"Child"` → `"children"`

---

### 🔹 ანუ

- `mongoose.model("User", ...)` → გამოიყენებს `"users"` კოლექციას
- `mongoose.model("Book", ...)` → გამოიყენებს `"books"` კოლექციას
- `mongoose.model("Person", ...)` → გამოიყენებს `"people"` კოლექციას

---

### 🔑 რატომ აკეთებს ასე?

იმიტომ, რომ ერთ მოდელს ჩვეულებრივ **ბევრი დოკუმენტი** ექნება (არა ერთი), ამიტომ კოლექცია ყოველთვის უნდა იყოს **მრავლობითში** MongoDB-ში.

თუ გინდა **mongoose-მა არ გადააკეთოს სახელები**, შეგიძლია გამოიყენო **`collection` პარამეტრი სქემაში**:

```js
const userSchema = new mongoose.Schema(
  {
    name: String,
    email: String,
  },
  {
    collection: "myUsers", // აქ შენ თვითონ ადგენი კოლექციის სახელს
  }
);

const User = mongoose.model("User", userSchema);
```

- ახლა MongoDB-ში **`myUsers`** კოლექცია შეიქმნება, არა `"users"`.
- მოდელის სახელი `"User"` ისევ რჩება, მაგრამ კოლექციის სახელი უკვე შენ მართავ.
